# Monsterpedia

A Pokédex for Monster Energy: 325 flavours and variants, numbered, with a photo of each can. Tick off the ones you've drunk; progress is saved in your browser.

Plain static site, no build step: open `index.html` or serve the folder. Pushing to `main` auto-deploys on Vercel.

- **Add/fix a flavour:** edit `flavours.js` (`n` name, `l` line, `i` photo URL, `c`/`a` can colours for the drawn fallback, `y` release year if known). Numbers follow the order in the file.
- **Source:** the community-made [ListChallenges list](https://www.listchallenges.com/ultimate-list-of-all-monster-energy-2026). Photos are loaded from there; if one fails, a drawn can in its colours is shown instead.
- Release years are best-effort and only shown where known.

Fan project, not affiliated with or endorsed by Monster Energy. Logo via Wikimedia Commons.
