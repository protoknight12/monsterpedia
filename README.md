# Monsterpedia

Every Monster Energy flavour in one place. Tick off the ones you've drunk; progress is saved in your browser.

Plain static site, no build step: open `index.html` or serve the folder.

- **Add/fix a flavour:** edit `flavours.js` (`n` name, `l` line, `y` year, `c`/`a` can colours for the drawing, `i` photo path, `d` discontinued).
- **Photos:** from [Open Food Facts](https://world.openfoodfacts.org), CC-BY-SA. Flavours without a photo get a drawn can in their colours.
- Release years are best-effort.

Fan project, not affiliated with Monster Energy.
